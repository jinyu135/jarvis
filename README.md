# Jarvis

Jarvis는 공개 배포를 목표로 하는 Windows 데스크톱 에이전트의 베타 버전입니다. 텍스트나 음성으로 요청하면 파일, Windows 앱, 브라우저를 오가는 여러 단계를 계획하고 수행하며 진행 상황을 보여줍니다. 한국어로 대화하고, 기본 모델은 `gpt-6-luna`입니다.

예를 들어 다운로드 폴더의 오래된 설치 파일을 정리하거나 메모리를 많이 쓰는 백그라운드 프로그램을 찾을 수 있습니다. **이 두 요청은 사용 예시일 뿐 Jarvis의 대표 기능이나 작업 범위를 정의하지 않습니다.** 작업 가능 여부는 PC 상태, 앱 접근 권한, 연결된 도구에 따라 달라집니다.

## 사용하기

1. GitHub Releases에 `JarvisSetup.exe`가 게시되면 해당 파일을 다운로드해 설치합니다. 아직 릴리스가 게시되지 않았다면 아래의 개발 빌드 절차를 사용합니다.
2. Jarvis를 열고 **ChatGPT 로그인**을 누릅니다. 브라우저에서 ChatGPT 계정 인증을 마치면 앱으로 돌아옵니다. 별도의 OpenAI API 키 입력은 필요하지 않습니다. Jarvis는 [Codex App Server의 ChatGPT 로그인](https://learn.chatgpt.com/docs/app-server)을 사용합니다.
3. 요청을 입력하거나 마이크 버튼, `Ctrl+Shift+J`, 호출어 **“자비스”**로 음성 명령을 시작합니다. 호출어는 기본적으로 켜져 있으며 설정에서 끌 수 있습니다.
4. 삭제, 설치, 메시지 전송, 중요한 설정 변경처럼 영향이 큰 작업은 표시된 대상과 내용을 읽고 승인 여부를 선택합니다.

음성 인식을 처음 사용할 때 Jarvis는 `whisper.cpp` 실행 파일과 한국어를 포함하는 다국어 모델을 `%LOCALAPPDATA%\Jarvis\voice`에 내려받습니다. 모델 크기는 약 142 MiB이며 첫 실행에는 인터넷 연결과 다운로드 시간이 필요합니다. 음성 인식은 PC에서 실행되고, 인식된 명령은 에이전트에게 전달됩니다. 답변 읽기는 Electron 화면의 `speechSynthesis`를 사용합니다. 모델이나 실행 파일의 설치가 실패하면 텍스트 입력은 계속 사용할 수 있습니다.

## 동작 방식과 권한

Jarvis는 Electron 화면, Codex App Server, Windows 데스크톱 도구, 로컬 음성 인식 모듈로 구성됩니다. 현재 데스크톱 도구는 화면 캡처, 열린 창 조회, 클릭, 스크롤, 키 입력, 상위 메모리 사용 프로세스 조회를 제공합니다. Codex는 요청에 따라 파일 및 명령 도구도 사용할 수 있습니다. [MCP 도구 승인 설정](https://learn.chatgpt.com/docs/extend/mcp)을 통해 영향이 큰 작업에 확인 단계를 둡니다.

Jarvis는 작업 결과를 도구로 확인하도록 지시받지만, 베타 버전의 판단과 화면 조작은 틀릴 수 있습니다. 승인 창에는 구체적인 대상과 동작이 표시되어야 하며, 내용이 다르거나 불명확하면 거절하세요. Windows의 사용자 계정 컨트롤(UAC) 및 자격 증명 입력은 사용자가 직접 처리해야 합니다. Codex의 파일·명령 실행 권한 때문에 영향이 작은 작업에도 추가 권한 승인이 나타날 수 있습니다.

ChatGPT 계정 로그인은 Codex 인증에 사용됩니다. `gpt-6-luna` 이용 가능 여부와 사용 한도는 계정 및 제공 상태에 따라 달라질 수 있습니다. Codex App Server의 로컬 통합 인터페이스는 [공식 문서에서 실험적 기능](https://learn.chatgpt.com/docs/app-server)으로 설명됩니다. 이 베타는 자동 업데이트와 코드 서명을 제공하지 않습니다. 서명되지 않은 설치 파일에는 Windows SmartScreen 경고가 나타날 수 있습니다.

## 개발 빌드

Windows x64, Node.js 22.12 이상 및 npm이 필요합니다. 프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
npm ci
npm start
```

설치 파일을 만들려면:

```powershell
npm run make
```

설치 파일과 SHA-256 목록은 `dist/JarvisSetup.exe`, `dist/SHA256SUMS.txt`에 복사됩니다. Squirrel 빌드 중 한글 경로에서 리소스 편집이 실패할 수 있어 Forge의 중간 출력은 시스템 임시 폴더를 사용합니다. 패키지 구조만 확인하려면 `npm run package`를 실행합니다. 빌드된 앱에서 로그인, 대화, 승인, 음성 초기 설치와 입력을 확인한 뒤 배포하세요.

## GitHub Releases 배포

이 저장소에 소스와 빌드 설정이 있어도 설치 파일이 자동으로 공개되지는 않습니다. 배포자는 공개 GitHub 저장소에 코드를 올리고, 버전 `0.1.0-beta.2`의 **Pre-release**를 만든 다음 빌드한 `JarvisSetup.exe`를 첨부해야 합니다. 설치 파일의 SHA-256 값과 지원 환경, 알려진 문제를 릴리스 설명에 기록하고, 공개 전에 깨끗한 Windows 환경에서 설치 및 로그인 흐름을 확인합니다. 릴리스가 게시된 뒤에야 누구나 다운로드할 수 있는 GitHub Releases 링크가 생깁니다.
