# Jarvis 0.1.0-beta.3

Windows x64 공개 베타 설치 파일: `JarvisSetup.exe`.

SHA-256: 공개 `SHA256SUMS.txt`와 GitHub 릴리스 설명의 값을 사용하세요.

## 변경 사항

- 새 대화를 만들고 App Server에 저장된 Jarvis 대화를 다시 엽니다. 대화 목록에는 App Server 스레드 제목과 최근 메시지를 표시합니다.
- 진행 중인 요청을 중단할 수 있습니다. Codex App Server는 해당 turn을 `interrupted`로 끝냅니다. 중단은 이미 완료된 파일 변경이나 PC 작업을 되돌리지 않습니다.
- 요청한 폴더 안에서 파일을 검색하고, 파일 정보를 확인하고, 파일을 복사·이동·이름 변경할 수 있습니다. 대상이 이미 있으면 덮어쓰지 않고 오류로 끝냅니다.
- 파일·폴더를 Windows 휴지통으로 이동하고, 프로세스를 PID와 이름으로 종료하는 동작은 정확한 대상과 영향을 보여주는 실행 직전 승인 단계를 거칩니다. 영구 삭제 기능은 없습니다.
- 앱 실행, 창 전환, CPU·메모리·고정 디스크 및 프로세스 조회 도구를 추가했습니다.
- `JarvisSetup.exe`는 Squirrel.Windows per-user 설치 파일입니다. 관리자 권한을 요구하거나 별도 설치 마법사를 표시하지 않고, 시작 메뉴 바로 가기를 등록한 뒤 앱을 엽니다. 설치·업데이트 이벤트에서 중복 실행을 막고 앱 단일 실행 잠금을 적용합니다.
- 기본 모델 `gpt-6-luna`, ChatGPT 로그인, 한국어 텍스트·음성, Electron Forge 및 Codex App Server `0.156.1`을 유지합니다. Codex App Server API는 실험적입니다.

## 설치

`JarvisSetup.exe`를 실행합니다. 설치가 끝나면 Jarvis가 열립니다. 나중에 시작 메뉴에서 Jarvis를 다시 열 수 있습니다. 음성 인식의 첫 실행에는 인터넷 연결과 로컬 모델 다운로드가 필요합니다.

## 알려진 제한

- Codex App Server API가 실험적이며 계정별 모델 접근 및 요청 한도가 다를 수 있습니다.
- Gemini, Claude, Grok API 연결은 이번 베타에 포함하지 않습니다.
- 검색은 요청마다 지정된 폴더에서 실행되며 드라이브 전체 검색이나 색인은 하지 않습니다.
- 파일 덮어쓰기와 영구 삭제는 지원하지 않습니다.
- 설치 파일은 서명되지 않았습니다. Windows SmartScreen 경고가 표시될 수 있습니다.
- 자동 업데이트는 지원하지 않습니다.
- 새 Windows 사용자 계정에서의 깨끗한 설치 검증은 이 빌드 환경에서 수행할 수 없었습니다. 기존 beta.1 설치 환경에 설치 파일을 실행한 셸 기반 시도에서도 버전 변경이 확인되지 않았습니다. 따라서 beta.1 업그레이드 동작은 아직 확인되지 않았으며, Squirrel 설치 로그에도 해당 시도가 기록되지 않았습니다.
