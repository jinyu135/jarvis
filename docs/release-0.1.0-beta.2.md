# Jarvis 0.1.0-beta.2

Windows x64용 공개 베타입니다. 설치 파일: `JarvisSetup.exe`.

SHA-256: `b13c041c4a9e51e3076d6894d6fa69b0f13f3b0e371bdefc2ce46df5f45de0e7`

## 포함된 기능

- ChatGPT 계정으로 Codex App Server에 로그인하고 `gpt-6-luna`를 기본 모델로 사용합니다. API 키 입력은 필요하지 않습니다.
- 한국어 텍스트 대화와 작업 진행 상황을 표시합니다. 파일, Windows 앱, 브라우저를 오가는 여러 단계의 요청을 처리할 수 있도록 구성했습니다.
- 마이크 버튼, `Ctrl+Shift+J`, `자비스` 호출어로 음성 명령을 받습니다. 첫 실행 시 로컬 whisper.cpp 실행 파일과 다국어 모델을 내려받습니다.
- 화면 캡처, 창 목록, 마우스·키보드 조작, 메모리 사용량 조회를 위한 Windows 도구를 제공합니다.
- 삭제·설치·메시지 전송 등 영향이 큰 작업에는 구체적인 승인 요청을 띄우도록 설정했습니다.

## 설치와 확인

`JarvisSetup.exe`를 실행한 뒤 ChatGPT 계정으로 로그인합니다. 음성 기능에는 마이크와 첫 실행 시 인터넷 연결이 필요합니다. 다운로드 무결성은 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 베타 제한

- Codex App Server는 공식 문서에서 실험적 인터페이스로 설명됩니다. 계정별 모델 사용 가능 여부와 한도가 다를 수 있습니다.
- 설치 파일에 코드 서명이 없으므로 Windows SmartScreen 경고가 표시될 수 있습니다.
- 자동 업데이트는 아직 지원하지 않습니다.
- 실제 계정 로그인, 마이크 입력, 설치 후 실행은 배포 전 별도 사용자 환경 확인이 필요합니다.
- 보안 취약점이 수정된 Electron Forge 8.0.0-alpha.10 빌드 도구를 사용합니다. 소스를 직접 빌드하려면 Node.js 22.12 이상이 필요합니다.
- 현재 전체 npm 의존성 감사에서 취약점이 보고되지 않았습니다.
